# Rough Mixing

### Objective
Learn to balance all track levels and set the foundation of a song mix.

### Steps
1. Load the *Rough Mixing* scene from the Main Menu.
2. Place each audio source (kick, bass, synth, vocal) in the sound space.
3. Use the **volume sliders** to balance loudness between instruments.
4. Adjust **panning** for stereo placement (left/right field).
5. Check the **master meter**—avoid clipping above 0 dB.

### Tips
- Trust your ears, not just the meters.
- Aim for a balanced sound where no track dominates.
- Nina can say: “Try lowering the snare by 2 dB to match the vocal energy.”
